# APK Sentinel

Automated fraud-APK analysis platform: one engine, two surfaces — an analyst dashboard for bank SOC teams and an on-phone scanner ("Sentinel Shield") that intercepts malicious APKs before install.

> **Docs are the source of truth.**
> - [`APK-SENTINEL-REFERENCE.md`](./APK-SENTINEL-REFERENCE.md) — full technical spec (architecture, APIs, rules, LLM contract).
> - [`TEAM-WORKPLAN.md`](./TEAM-WORKPLAN.md) — who builds what, when, and how to verify it.
> - [`AGENTS.md`](./AGENTS.md) — standing instructions for AI assistants.
> - [`DEVLOG.md`](./DEVLOG.md) — shared handoff journal; read before you start, write when you stop.

## Repo layout

```
server/     FastAPI backend: analysis pipeline, rules engine, LLM layer (Python 3.11+)
  app/        application code (routers, services, data/rules.yaml)
  storage/    runtime artifacts (apks/, decompiled/, reports/) — gitignored
  fixtures/   pre-decompiled sample code so GenAI work never blocks on jadx
  samples/    demo APKs — NEVER install; *.apk gitignored
client/     React dashboard (Vite + Tailwind + shadcn/ui)
android/    Sentinel Shield scanner app (Kotlin) — full project is generated by Android Studio here
docs/       demo script & pitch material
```

## Quick start

One-shot environment setup — idempotent, safe to re-run:
- macOS/Linux: `./setup.sh` (flags: `--with-android`, `--with-docker`)
- Windows: `powershell -ExecutionPolicy Bypass -File .\setup.ps1` (flags: `-WithAndroid`, `-WithDocker`)

### Backend
```bash
cd server
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
brew install jadx                 # decompiler; see Reference §15
cp .env.example .env              # fill LLM keys
uvicorn app.main:app --reload --port 8000
```

### Dashboard
```bash
cd client
npm install
cp .env.example .env              # set VITE_API_BASE (+ VITE_USE_MOCKS for offline dev)
npm run dev                       # http://localhost:5173
```

### Android
Open `android/` in Android Studio → run on device. Set API base URL to your laptop's LAN IP (Reference §14).

⚠️ **Sample APKs in `server/samples/` are malware-like test artifacts. Never install them on a real device; analyze only inside Docker.**
